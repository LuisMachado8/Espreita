# Espreita! 🐇

Jogo Android de reflexos em pixel art: um coelho espreita de um de 6 arbustos durante milissegundos e tens de lhe tocar a tempo. Cuidado com a raposa.

**Stack:** Java · Android SDK (min API 24) · `SurfaceView` + `Canvas`, sem engine de jogos

**Estado:** em desenvolvimento — Fase 1 (fundações: projeto, Git e game loop)

Projeto de aprendizagem construído por fases, com tickets, critérios de aceitação e code review.
